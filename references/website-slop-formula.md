# Website Slop Formula

The generic AI website template, why it converts poorly, and how to break out of it.

## The Formula

Every AI website builder (v0, Lovable, Bolt, Framer AI) produces variations of the same template:

```
1. Giant hero section
   - Dark or gradient background
   - Vague aspirational headline ("Build the future")
   - Sub-headline explaining what the product does (because the headline didn't)
   - "Get started for free" CTA button
   - Optional: abstract gradient blob decoration

2. Logo trust bar
   - "Trusted by 10,000+ teams" (suspiciously round number)
   - Row of grayscale logos

3. Three-column feature grid
   - Icon + heading + one-sentence description
   - Each column identical weight
   - Icons from the same set (Lucide, Heroicons)

4. Product screenshot or demo section
   - Often AI-generated or mockup
   - Floating in space with gradient shadow

5. Testimonial cards
   - 3 cards, each with quote + name + title + avatar
   - Avatars often AI-generated
   - Quotes suspiciously polished

6. Pricing table
   - 3 tiers (Free, Pro, Enterprise)
   - Middle tier highlighted
   - "Most popular" badge

7. Final CTA section
   - Repeat of the hero CTA
   - "Start your free trial today"
   - Gradient or dark background
```

This formula is so ubiquitous that it has become meaningless. Users pattern-match it as "another SaaS landing page" and bounce. AI slop websites record conversion rates **91% lower** than quality, differentiated sites.

## The Specific Tells

### Headlines That Mean Nothing
- "Build the future" / "Reimagine what's possible" / "Empower your team"
- "The [category] platform for modern teams"
- "Your all-in-one [category] solution"
- **The test**: Could you put any product's name in front of this headline? If yes, it says nothing.
- **Fix**: Say what the product does, specifically, in a way only your product can claim. "Deploys your Next.js app in 8 seconds" beats "Deploy faster."

### The Purple Problem
Purple/indigo as the primary color. So widespread it has its own name: the "AI Purple Problem." AI tools trained on Tailwind and modern SaaS defaults output purple because it's the most common "modern" color in training data.
- **Fix**: Choose a color that comes from the brand, not from Tailwind's default palette. If your color could be generated by typing "modern SaaS website" into v0, pick a different color.

### Copy That Applies to Everyone
Feature descriptions generic enough to work for any product. "Powerful analytics" — what analytics? "Seamless collaboration" — how, specifically? "Enterprise-grade security" — what certifications?
- **Fix**: Every feature description should include a specific detail that only YOUR product has. A number, a mechanism, a comparison.

### Fake Social Proof
- "Trusted by 10,000+ teams" without naming any
- Testimonials that read like they were AI-generated (they probably were)
- Logos of companies that don't actually use the product
- **Fix**: Fewer, real testimonials beat many fake ones. One specific case study with numbers beats 10 generic quotes. If you don't have social proof yet, don't fake it — show the product instead.

### Gradient Blob Decorations
Abstract gradient shapes floating behind content. They serve no function. They communicate nothing. They exist because the template had a `<div class="blob">`.
- **Fix**: Delete them. If the page doesn't work without the blobs, the layout needs fixing, not decoration.

### The "Get Started Free" Everywhere
Every CTA is "Get started for free" or "Start your free trial." The same call to action regardless of where the user is in the page or their intent.
- **Fix**: CTAs should match context. Top of page: "See how it works." After features: "Try [specific feature]." After pricing: "Start free trial." After testimonials: "Read the case study."

### Uniform Spacing and Rhythm
Every section has the same padding. Every element has the same margin. The page scrolls at one visual tempo with no acceleration or rest.
- **Fix**: Vary the rhythm. Dense feature section > full-bleed image break > spacious testimonial > tight pricing grid. The variety keeps attention.

### Missing Personality
No custom illustrations. No opinionated copy. No unusual layout choices. No micro-interactions. No brand voice. The website is a container, not an experience.
- **Fix**: One distinctive choice per section. An unexpected illustration style. A bold typography choice. A layout that breaks the grid. An interaction that surprises. Not everything — one thing that makes it memorable.

## What to Do Instead

### Show the Product
The most effective hero section isn't a headline — it's the product in action. A real screenshot, a GIF of the workflow, an interactive demo. Let the product sell itself.

### Tell a Story
Instead of Feature Grid, walk the user through a scenario. "You wake up to 47 Slack messages. Here's what happens next." Narrative > catalog.

### One Thing Per Section
Instead of three equal features, go deep on one. Full-bleed screenshot, detailed walkthrough, real example. Then scroll to the next one. Sequential > simultaneous.

### Real Numbers
"Deploys in 8 seconds" beats "Lightning fast." "$23/mo" beats "Affordable pricing." "3 steps" beats "Easy setup." Numbers are specific. Adjectives are AI.

### Specific Comparisons
"Unlike [competitor], we [specific difference]" is more useful and more human than "The best [category] platform." Taking a position signals confidence.

### Unconventional Structure
Not every website needs hero > features > testimonials > pricing. Consider:
- **Product-first**: Start with an interactive demo, no hero
- **Story-first**: Start with the problem, build to the solution
- **Proof-first**: Start with the case study, end with the product
- **Minimal**: One page, one scroll, one message, one CTA
- **Documentation-style**: Treat the landing page like clean docs with examples

### Break the Visual Template
- Asymmetric layouts instead of centered everything
- Full-bleed sections that break the container
- Typography as hero element (massive text, no imagery)
- Real photography instead of illustrations or gradients
- Intentional use of whitespace (editorial) or density (cockpit)
- Color that couldn't have been generated by default

## The Website Slop Checklist

- [ ] Headline says something only THIS product can claim
- [ ] Primary color is brand-derived, not Tailwind/AI default
- [ ] Features have specific details (numbers, mechanisms, comparisons)
- [ ] Social proof is real and verifiable
- [ ] No decorative gradient blobs
- [ ] CTAs vary by context and position
- [ ] Visual rhythm varies between sections
- [ ] At least one element that breaks the standard template
- [ ] Copy passes the "swap in another product name" test
- [ ] A competitor couldn't use this page with their logo
